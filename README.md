# Xoto Task Hub

I need to build a task tracker app for a company called Xoto Proptech. The platform is aimed to track work for the employees on a daily basis. The admin view should cover all metrics including time in, time out, tasks worked on, data, etc. The team manager should see tasks for their team. The employee should be able to log in, log out and add tasks completed for the day in the fields and form as easy as possible. Login using company email and password for each user and RBAC
